# План TravelMate

**Цель:** локальная русскоязычная анкета для демонстрации лабораторной работы.
**Архитектура:** существующий MainPage, XAML + C# code-behind, без новых пакетов и слоёв.
**Основание:** полное задание из приложенного Pasted text.txt.

1. Заменить MainPage.xaml: светлый фон, бирюзовые карточки, все требуемые поля и явные свойства, уникальные имена `_…_`, вертикальная прокрутка, x:Reference для длительности.
2. Добавить Resources/Images/travel_scene.svg. Ресурс уже включается существующим MauiImage wildcard.
3. Реализовать MainPage.xaml.cs: проверка имени и положительного decimal-бюджета, русские сообщения, все ответы в сводке, скрытие устаревшего результата при любом изменении, полный сброс.
4. Установить начальную дату через XAML-привязку к дате запуска + 14 дней; диапазон от даты запуска до +2 лет. Повторный сброс возвращает эту же дату.
5. Обновить название приложения и Shell без изменения имени проекта, namespace и TargetFrameworks.
6. Проверить контракт XAML, крайние случаи бюджета и округления длительности; выполнить restore и Android build через существующее решение. Проверить доступность Android-устройства.
7. Подготовить docs/TravelMate-report.md с таблицей требований, фактическими результатами и ручными сценариями.

**Риски для проверки:** пустое/пробельное имя; нулевой, отрицательный, слишком большой и нечисловой бюджет; точка/запятая и пробелы в сумме; округление длительности у полуцелых значений; события при InitializeComponent и сбросе; изменение любого поля после сводки; узкий экран и длинные пожелания.

Работа выполняется в указанной пользователем папке. Git-репозиторий отсутствует, поэтому worktree и коммиты неприменимы. Пользователь явно разрешил последовательную реализацию без промежуточных остановок.
